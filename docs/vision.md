# Vision

Define an agent project as files and use it with the capable harness you already trust.  
Compile portable instructions, skills, and managed capabilities into native Claude Code and Codex setups without replacing their model loops or interfaces.  
For headless use, add a session-aware gateway that connects external input and governs only what crosses its managed boundary.

## Boundary

The selected harness owns intelligence: model calls, context management,
planning, native tools, approvals, and interactive UX. The tool owns the
portable filesystem contract and the capabilities routed through its managed
boundary.

Interactive users work directly in Claude Code or Codex after applying a
projection. Headless users may place the gateway between an input source and a
local harness process. The gateway does not become another chat UI or model
loop.

Harness-native tools remain valid but unmanaged. The tool never claims that it
can enforce instructions, inspect every native effect, or make model behavior
safe from outside the harness.
